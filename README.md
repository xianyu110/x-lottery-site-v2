# X Platform Follow Lottery Site (X 关注领月卡抽奖系统)

一个简单、美观且功能完整的抽奖网站。用户只需在 X (Twitter) 上关注指定博主，即可领取月卡奖品。支持本地运行和 Vercel 一键部署。

## 🌟 核心特性

- **三步走简约流程**：登录 X -> 点击关注 -> 自动校验并领取奖品。
- **真实奖品池管理**：通过 `prizes.json` 管理月卡兑换码，支持自动发放与状态锁定，防止重复领取。
- **响应式设计**：基于 Tailwind CSS 构建，完美适配手机和桌面浏览器。
- **Serverless 友好**：兼容 Vercel Serverless Functions，无需部署传统服务器。
- **本地开发环境**：内置 Express 服务器，方便在本地进行完整的功能测试。

## 🚀 快速开始 (本地运行)

### 1. 克隆项目
```bash
git clone https://github.com/xianyu110/x-lottery-site-v2.git
cd x-lottery-site-v2
```

### 2. 安装依赖
```bash
npm install
```

### 3. 运行服务器
```bash
node server.js
```
访问 [http://localhost:3000](http://localhost:3000) 即可开始测试。

## 📦 奖品管理

打开根目录下的 `prizes.json` 文件：
- **添加奖品**：在 `prizes` 数组中添加新的对象 `{"code": "你的兑换码", "status": "available"}`。
- **状态说明**：
  - `available`: 可领取。
  - `assigned`: 已被用户领取。

## 🌐 部署到 Vercel

1. 将此仓库 Fork 或上传到你自己的 GitHub。
2. 登录 [Vercel](https://vercel.com/)。
3. 点击 "Add New Project" 并选择此仓库。
4. 点击 "Deploy"。Vercel 会自动识别 `server.js` 并作为后端运行。
